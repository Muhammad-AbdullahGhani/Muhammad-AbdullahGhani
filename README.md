## ⚡ Professional Summary

I'm an Associate Software Engineer who builds products end to end: ASP.NET Core backends, React Native mobile apps, and AI systems that sit on top of them. I've shipped a mobile app to real users, built production-style APIs in C#, and engineered agentic and RAG pipelines with LangChain and LangGraph. I like the point where solid backend fundamentals meet LLMs.

- 💻 **Backend Development:** Designing and integrating APIs with C#, .NET, and ASP.NET Core.
- 📱 **Mobile Development:** Cross-platform apps with React Native and JavaScript/TypeScript, including a shipped consumer app.
- 🗄️ **Data & Architecture:** Databases, API integration, object-oriented design, and maintainable application architecture.
- 🤖 **AI Engineering:** LLM applications, RAG pipelines, agentic workflows, and model training with LangChain, LangGraph, and PyTorch.
- 🌐 **Open Source:** Contributed to VidXP, including a merged fix for multimodal search interval fusion.
